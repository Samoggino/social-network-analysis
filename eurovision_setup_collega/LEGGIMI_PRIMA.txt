EUROVISION SNA — SETUP PER COLLEGA (FINO ALLA FASE PRE-RQ1)
================================================================

SCOPO
Riprodurre le matrici di voto Eurovision jury/televoto e l'analisi
esplorativa iniziale, senza eseguire RQ1, RQ2, RQ3 o RQ4.

1. PREREQUISITI
- Python 3.10 o successivo (su Windows verificare con: py --version)
- VS Code e terminale PowerShell (facoltativi)

2. SCARICARE IL DATASET ORIGINALE (NON INCLUSO NEL PACCHETTO)
- Aprire https://github.com/EurovisionAPI/dataset
- Premere Code > Download ZIP
- Estrarre l'archivio e mettere la cartella "dataset-main" nella
  stessa cartella di build_eurovision_data.py.
- Se si e' gia' estratta una cartella dataset-main dentro un'altra
  dataset-main, va bene: lo script riconosce entrambe le strutture.

3. STRUTTURA PRIMA DELL'ESECUZIONE
  eurovision-sna/
  |-- build_eurovision_data.py
  |-- verifica_dati.py
  |-- dataset-main/
  |   `-- data/senior/2016/...  (anche dataset-main/dataset-main e' supportato)
  `-- src/
      `-- exploratory_analysis.py

4. GENERARE LE 20 MATRICI (NESSUNA LIBRERIA EXTRA)
Aprire PowerShell nella cartella eurovision-sna ed eseguire:
  py build_eurovision_data.py

Risultato atteso con lo snapshot originale:
  Annual matrices: 20
  Eligible national votes: 19698
  Countries: 45
  Done.

File generati:
  processed_data/tables/votes_master.csv
  processed_data/tables/nodes.csv
  processed_data/matrices/2016_jury.csv ... 2026_public.csv

Ogni riga delle matrici e' un Paese votante, ogni colonna un Paese.
Una cella vuota indica un voto strutturalmente impossibile;
uno zero indica un destinatario ammissibile che non ha ricevuto punti.
Voti positivi: 1,2,3,4,5,6,7,8,10,12.
Le 10 edizioni sono 2016,17,18,19,21,22,23,24,25,26; 2020 escluso.
I voti WLD (resto del mondo) sono esclusi dal set di votanti nazionali.

5. CONTROLLARE LE MATRICI
  py verifica_dati.py
Deve stampare VERIFICA RIUSCITA e, con lo snapshot originario,
20 matrici, 19698 voti ammissibili, 45 Paesi.
Il dataset GitHub e' aggiornabile: differenze di contenuto vanno
indagate, non corrette a mano per ottenere gli stessi conteggi.

6. ANALISI ESPLORATIVA (SE SI VUOLE ARRIVARE ALLO STESSO PUNTO PRE-RQ1)
Installare le librerie:
  py -m pip install networkx matplotlib
Eseguire:
  py src/exploratory_analysis.py

Risultato atteso per lo snapshot originario:
  Matrices read: 20
  Country-level observations: 786
  Completed. Source matrices were not modified.

File aggiuntivi:
  results/exploratory/network_summary.csv
  results/exploratory/country_metrics.csv
  figures/exploratory/ (immagini illustrative)

7. NOTE DI METODO
- Grafo orientato e pesato: votante -> finalista, peso = punti.
- 0 non e' un arco positivo; vuoto e' un'opportunita' inesistente.
- La validazione degli script e' interna; il confronto indipendente
  con le fonti ufficiali Eurovision NON e' stato completato.
- Il dataset e' di terze parti (EurovisionAPI), non una fonte EBU.
- In questo pacchetto NON ci sono le analisi delle Research Questions.
- Per confrontare esattamente gli output e' importante usare la
  stessa revisione del repository; il download ZIP di GitHub puo'
  cambiare se il repository viene aggiornato.

Fonte: https://github.com/EurovisionAPI/dataset
